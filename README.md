# SOC Analyst Dashboard

Mini SIEM/SOC dashboard built using Python and Streamlit.

## Features
- IOC Detection
- Brute Force Detection
- Threat Intelligence (AbuseIPDB)
- Email Notifications
- SQLite Database
- Dashboard Metrics
- Search by IP
- Date Filters
- Bar Chart
- Pie Chart
- Timeline Graph
- CSV Export
- Severity Levels
- Clear Alerts
- Auto Refresh
- Dark Mode

## Technologies Used
- Python
- Streamlit
- SQLite
- Matplotlib
- AbuseIPDB API
- SMTP Email

## Workflow
Log Files → Detection Engine → Threat Intelligence → Database → Dashboard → Reports → Email Alerts
